# 智愈（SmartMed）— Agent 配置

## 语言规则

所有思考（thinking）与回复（reply）必须使用中文。

## Agent skills

### Issue tracker

Local markdown — issues 以文件形式存放在 `.scratch/<feature>/issues/` 下。See `docs/agents/issue-tracker.md`.

### Triage labels

默认 5 标签（needs-triage / needs-info / ready-for-agent / ready-for-human / wontfix）。See `docs/agents/triage-labels.md`.

### Domain docs

Single-context — 根目录 `CONTEXT.md` + `docs/adr/`。See `docs/agents/domain.md`.
