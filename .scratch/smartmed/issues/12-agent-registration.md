# 12 — Agent 预约挂号

**What to build:** 导诊完成后，Agent 引导患者选择排班时段，生成挂号确认卡片（草稿），患者点击确认后完成挂号并返回凭证卡片，号源不足时提示重新选择。

**Blocked by:** 11 — Agent 智能导诊, 05 — 挂号全链路

**Status:** ready-for-agent

- [ ] Java 工具实现：排班查询（按科室/医生/日期查可用排班和余量）
- [ ] Java 工具实现：挂号草稿生成（收集参数 → 校验 → 写 Redis 草稿 → 返回草稿 ID）
- [ ] Agent 展示排班选项 → 用户选择 → 调用草稿工具 → 生成确认卡片
- [ ] 确认卡片内容：医生、科室、时间、地点 + [确认挂号] [取消] 按钮
- [ ] 用户确认 → 前端调挂号确认接口 → 成功返回凭证卡片
- [ ] 号源刚被抢完 → Agent 提示"该时段已满"并推荐其他时段
- [ ] 挂号成功 → Agent 提示"就诊前 1 天会提醒您"
- [ ] pytest 测试：正常挂号流程、号源不足场景、草稿过期场景
