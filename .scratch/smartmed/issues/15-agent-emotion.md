# 15 — Agent 情感识别

**What to build:** Agent 在对话中识别用户情绪（焦虑、疼痛、困惑、满意），自动调整话术风格（安抚、优先处理、通俗解释、温馨回应），对话体验从"冷冰冰的业务处理"升级为"有温度的健康伴侣"。

**Blocked by:** 12 — Agent 预约挂号

**Status:** ready-for-agent

- [ ] 情感识别模块：分析用户消息中的情绪信号（关键词 + LLM 判断）
- [ ] 焦虑场景："是不是得了重病" → 安抚 + 理性分析 + 引导就医
- [ ] 疼痛场景：描述剧烈疼痛 → 优先处理 + 紧急建议 + 快速导诊
- [ ] 困惑场景："这个药怎么吃""看不懂" → 通俗解读 + 分步说明
- [ ] 满意场景：感谢 → 温馨回应 + 引导后续（用药提醒、复诊）
- [ ] 话术调整集成到 LangGraph 状态机：情绪标签注入 system prompt
- [ ] 主动关怀触发点：挂号成功提醒、问诊后 3 天回访话术、处方用完复诊提醒
- [ ] pytest 测试：各情绪场景识别准确性、话术风格切换
