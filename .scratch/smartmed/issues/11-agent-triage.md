# 11 — Agent 智能导诊

**What to build:** 患者描述症状后，Agent 能多轮追问细节（部位、持续时间、体温、伴随症状），识别紧急症状优先建议就医，非紧急时查询知识图谱推荐科室和医生，推荐附带可解释理由。

**Blocked by:** 09 — Agent 框架搭建, 04 — 排班与号源管理

**Status:** ready-for-agent

- [ ] 意图识别：区分导诊/挂号/问诊/购药/闲聊，进入对应子流程
- [ ] 多轮症状采集：追问部位、持续时间、严重程度、伴随症状、体温
- [ ] 紧急症状拦截：胸痛/大出血/呼吸困难 → 立即建议就医，不进入挂号流程
- [ ] Java 工具实现：知识图谱查询（症状→疾病→科室，返回推荐+理由）
- [ ] Java 工具实现：医生查询（按科室筛选，返回职称/擅长/好评率/可约时间）
- [ ] Agent 调用知识图谱工具 → 生成科室推荐（附"因为...所以推荐..."理由）
- [ ] Agent 调用医生查询工具 → 推荐 3 位医生（排序：好评率+号源+时间）
- [ ] 所有推荐标注"AI 建议仅供参考"
- [ ] pytest 测试：意图识别准确性、紧急症状拦截、工具调用顺序
