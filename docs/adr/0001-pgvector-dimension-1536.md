# 0001 - pgvector 向量维度定为 1536

RAG 备用检索的数据层在 01 基础设施阶段预建，向量列维度 `vector(1536)` 锁定为对齐通义千问 `text-embedding-v2`（1536 维）。CONTEXT 第 7 节将 LLM 列为"通义/智谱/文心"可切换，但向量维度一旦建表即不可逆（改维度需 drop 列、重建 ivfflat 索引、重导全部 embedding），故必须在此刻拍板。选 1536 而非智谱的 1024，因通义列为 CONTEXT 首选模型；若后期切智谱，需执行一次维度迁移，这是已知成本。文心的 384 维因差距过大不作候选。

**Considered Options**: 1024（智谱对齐）、1536（通义对齐，采用）、不定维度延迟到 Agent 阶段（被否，因已决定预建向量表）。
